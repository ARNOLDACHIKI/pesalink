INSTRUCTIONS FOR WINDOWS USERS:

1. Install Docker Desktop for Windows:
   https://www.docker.com/products/docker-desktop/

2. Extract this zip file to a known directory, e.g., C:\Users\YourName\Documents\bulk_payment_validation_system

3. Open Command Prompt or PowerShell and navigate to the project directory:
   cd C:\Users\YourName\Documents\bulk_payment_validation_system

4. Build and start the Docker container:
   docker-compose build
   docker-compose up

5. Visit http://localhost:5000 in your browser to access the dashboard.

6. To stop the system:
   docker-compose down
